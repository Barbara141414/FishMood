# FishMood 三维鱼缸 Web UI

纯 JavaScript / Three.js 0.170.0，依赖已保存在 dist/vendor 并保留 MIT 许可证。使用本地 HTTP 服务，无构建步骤，不调用外部 API、不含密钥。

启动：`python3 -m http.server 8080 --directory webui/dist`（项目根目录），访问 http://localhost:8080 。ES 模块需要 HTTP，不支持直接双击 file://。

## 场景与操作

- 90 × 60 × 50 cm 的三维鱼缸，参照 video0.mp4 预览帧及照片中的中央分叉沉木、明亮绿植、底砂和左侧进水管进行程序化示意建模。不是摄影测量或准确三维重建；背面和遮挡区域推定。
- 3 条立体神仙鱼：花斑、红顶、蓝银，参考照片花色；不是已确认的永久个体身份。
- 鼠标/单指拖拽环绕，滚轮/双指缩放；画布聚焦后方向键旋转、+/- 缩放。正面按钮复位相机，环绕按钮切换自动旋转。
- 保留个体选择、暂停、倍速、重置、日夜灯光、模拟投喂，增加模拟惊扰。

## 站点中的三鱼时序回放（2026-10-10 补记）

若从项目根目录启动 `python3 -m http.server 8765`，访问 `/site/ten-days.html` 或 `/site/thirty-days.html`，站点会用同源 iframe 给本 3D 场景发送**预计算的 synthetic 快照**，按时间轴更新三鱼位置、动作与隐藏状态显示；这不同于直接打开 `/webui/dist/` 时的交互生成器。十天 JSON 为 `dist/assets/ten-days.json`，三十天 JSON 为 `dist/assets/thirty-days.json`，由两个独立 Python 脚本生成，不能把它们当作真实逐鱼追踪。三十天页面还显示三模型概率和留出指标，这些值是预先拟合后保存在 JSON 中的，**3D 场景本身没有运行 LR/GAM/HMM 推理**。详见 `../outputs/FishMood-thirty-day-results.md`。

## 四维状态（下述为旧交互生成器）

参考根目录 MEMORY.md、fishwatch/simulation.py 和 project_config/simulation_parameters.json：H 饥饿驱动、S 紧张、E 探索倾向、F 疲劳均为 0–1。卡片显示生成器真值与当前随机行为（探索、觅食、休息、躲避、急冲），不是 LR/GAM/HMM 的推断概率；尚未将 3D 轨迹接入 Python 模型。

latent.js 复用默认状态更新公式、行为 softmax 分数与摄食概率；1 秒模拟播放对应 1 模拟分钟。E 和个体 B 固定。投放食物不直接降低 H，鱼接近投喂点并发生随机模拟进食后才降低 0.12；惊扰增加 S 0.18，S 随时间恢复；休息降低 F。0.125 秒固定模拟步长，倍速影响模拟时间。

本 UI 是三鱼三维交互扩展，不是 Python 单鱼生成器的逐帧复现：没有会话随机系数扰动和相机观测噪声；新增三维避障、简单避碰、日夜速度修饰；不代表群体等级或追逐模型。环境数值为示例固定值。
